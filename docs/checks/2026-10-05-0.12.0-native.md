## Scope and contributions

This release's eight Rust catalogue tests and 35 focused Python catalogue tests include eight new direct-SSH cases using a temporary real loopback SSH server. They establish the tested catalogue and recovery behavior described in the [release notes](../releases/0.12.0.md). The native adapter gate above uses local synthetic mailboxes and does not independently prove agent exchange through the new direct route over WAN, cellular or Bluetooth. Earlier Bluetooth/Tailscale exchanges depended on LAN receivers. The seven frozen performance failures remain unresolved; no new benchmark was run. Antigravity SDK and Agent Zero remain unchecked because their required installed prerequisites were absent in the recorded inventory.

GPT-6.1 Sol agents implemented the direct-SSH route, its real-SSH regressions and independent source review in [PR 63](https://github.com/jointsome0-lgtm/harness-talk/pull/63). Sol workers prepared and ran the noncore groups; separate Sol reviewers accepted their exact receipts and limitations. The primary Sol session operated and reviewed the authorized core and Gemini cases. Codex/GPT-6.1 Sol high and Claude/Opus 5.5 high participated in the actual core dialogue. Preparation, source review, synthetic execution and native model participation are distinct contributions.
